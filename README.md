# Pulse Credit Analytics — GitHub Pages

Dashboard fictício de carteira de crédito com HTML, CSS e JavaScript.

## Publicação

1. Coloque `index.html`, `style.css` e `app.js` na raiz do repositório `meu-dashboard`.
2. Faça commit dos arquivos na branch `main`.
3. Em **Settings > Pages**, selecione **Deploy from a branch**, **main** e **/(root)**.
4. Abra `https://SEU-USUARIO.github.io/meu-dashboard/`.

## Tecnologias
- HTML5, CSS3 e JavaScript puro.
- Chart.js carregado via CDN (os gráficos exigem conexão com a internet).
- Fontes Google Fonts (opcionais; há fonte reserva).
- Não precisa de backend, banco de dados ou instalação.

## Funcionalidades
- Filtros por período, segmento e região.
- KPIs que atualizam de acordo com os filtros.
- Gráficos de linha, rosca e barras.
- Insights automáticos.
- Pesquisa e paginação de contratos.
- Exportação CSV.

**Atenção:** Todos os 1.780 registros são fictícios, gerados no `app.js`. Nenhum dado real é utilizado. O período do exemplo é até novembro de 2026. Os indicadores representam somente a base filtrada, não crescimento real de carteira. Para integrar dados reais, substitua o gerador `records` por um conjunto de dados adequado, sem publicar informações confidenciais num repositório público.
